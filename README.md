## AWS Wordle

- A version of Wordle created using AWS Web Services, built using Lambda functions. The project's front-end was written in React. 
- To create this project, each Lambda function was uploaded seperately; these files have been condensed for ease of navigation. 
- The web service integrations were added, the initial React framework and styling were provided by an instructor.
